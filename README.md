# EmoCara 情緒模擬器

一個用來建立角色、跟角色聊天、觀察角色內心變化的小遊戲。純網頁，手機和電腦都能玩。

## 怎麼玩

打開 GitHub Pages 的網址就能玩，不用下載、不用安裝。

1. 按「＋ 新增角色」，在「角色」分頁用自己的話描述他。每個模組都有一句問題幫你想，空著的格子會直接跳過。
2. 到「聊天」分頁跟他說話（打開網頁時預設就在聊天）。按 Enter 送出。
   - 手動複製貼上（預設）：送出後按「複製提示詞」，貼到任何網頁版 AI，複製它的回覆，回來按「從剪貼簿貼上」。AI 回覆第一行會提醒「含劇透」，直接按複製就好。
   - Gemini 自動回覆：在左邊「設定」填自己的 Gemini 鑰匙。塞車會自動重試，失敗可以一鍵改用手動。
3. 回覆通過程式檢查就直接存。反悔：點他最新那句，按「取消這句」（會先跳警告）；想退更多句，點你自己的泡泡，按「從這句重來」（最近 30 句）。
4. 他的泡泡底下按「偷看」可以看他沒說出口的心裡話。
5. 「現實時間」開關：開著他會知道現在幾點、隔了多久；關著時間不流動。
   「設定提議」開關（預設開）：聊天裡他變了（剪頭髮、換工作……），AI 會提議改他的設定，放在角色分頁最上面，你同意才會改，不處理也沒關係。
   「放大」：聊天室鋪滿整個畫面，按「縮小」或 Esc 回來。
6. 「開新聊天」：沿用記憶（同一個他換個場景），或不沿用（複製一個不認識你的他）。
7. 「觀察者」分頁可以看他記得的近期經過、內心時間線、心理狀態和記憶。

## 資料存在哪裡

- 角色、對話、記憶都存在「你玩的那台裝置的瀏覽器」裡，不會上傳到任何地方。
- 要換裝置玩或備份：按角色頁右上角的「匯出備份」，到另一台裝置按「匯入角色」選那個檔案。對話紀錄會一起帶過去。
- Gemini 鑰匙也只存在那台裝置的瀏覽器裡，不會進 GitHub。
- 清除瀏覽器資料會把角色一起清掉，記得定期匯出備份。

## 給開發者

- 網頁在 `docs/`：`core.js`（資料整理、驗證、提示詞）、`store.js`（存取）、`ai.js`（Gemini）、`app.js`（畫面）。
- 測試：`node --test tests/*.test.js`
- 舊的 Python 電腦版在 `垃圾桶/2026-11-22_電腦版Python/`。
