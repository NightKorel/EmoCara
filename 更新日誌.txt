EmoCara 情緒模擬器 更新日誌（最新的寫在最上面）

2026-11-22 v0.1.5 聊天改成聊天軟體的樣子
- 對話改成泡泡：你講的在右邊，他講的在左邊，一句一個泡泡。上面標題寫「跟 某某 聊天」。
- 輸入框在對話框正下方。按 Enter 送出，Shift＋Enter 換行；用中文輸入法選字時按 Enter 不會誤送。輸入框會跟著字數長高。
- 新訊息出來會自動捲到最下面，切到聊天分頁時也會直接停在最新那句。
- 他的回覆直接出現在泡泡裡（虛線框＝還沒存），下面一行小字寫心情變化、想記住的事（勾了才存），按「確認」就存，按「不要」這句就不算，剛剛打的字會放回輸入框，方便改一改重送。
- 已經存的對話，泡泡下面一行小字寫「心情：……」「記住了 N 件事」，點一下可以看細節。
- 手動複製貼上：送出之後才出現，分成兩步「複製提示詞」「貼上回覆」。提示詞內容平常收起來，要看再點。
- 回覆方式（手動／Gemini）改成輸入框下面的小選單，預設還是手動。
- 上一句還沒按確認或不要的時候，不能送下一句，會跳提醒。
- 拿掉的：原本下面那塊「等待確認的回合」預覽區，改成直接在泡泡底下確認。

2026-11-22 v0.1.4 展開區塊會自動捲過去
- 修正：在頁面底部展開「進階」「更多基本資料」或聊天紀錄裡的折疊內容時，畫面不會動，展開的東西跑到畫面外面。現在展開後會自動捲到那一塊的開頭。

2026-11-22 v0.1.3 改成網頁版（手機、電腦都能玩）
- 整個遊戲改寫成純網頁，放在 docs/，用 GitHub Pages 發佈。打開網址就能玩，不用下載、不用 start.bat。
- 角色、對話、記憶存在玩的那台裝置的瀏覽器裡，不會上傳。
- 「匯出備份」的檔案現在會連對話紀錄一起帶走；到另一台裝置「匯入角色」就能接著聊。
- 匯入時如果那台裝置已經有同一個角色，會先問你：要用檔案蓋掉，還是另存一份新的。檔案比較舊的話會特別提醒。（以前的做法是一律另存新的。）
- 左邊多一個「設定」，可以填 Gemini 鑰匙和模型名稱，只存在那台裝置。填了之後，聊天可以選「自動：Gemini」直接回覆，不用複製貼上。
- 手動複製貼上的模式照舊保留，而且還是預設。
- 拿掉的：本機模型 Ollama（網頁放在網路上，連不到你電腦裡的 Ollama）。
- 驗證規則跟電腦版一樣：AI 只能提案，你按確認才會存。原本 25 個 Python 測試改寫成 24 個網頁版測試，全部通過（少的那一個是測資料庫欄位升級，網頁版沒有資料庫）。
- 舊的 Python 電腦版整套搬進 垃圾桶/2026-11-22_電腦版Python/，沒有刪。README.md 改寫成網頁版的說明，GPT 寫的舊版 README 也在那裡面。
- 角色資料不再存進 GitHub（舊資料庫只有一個空白角色，搬進 垃圾桶/2026-11-22_舊角色資料庫/）。

2026-11-22 v0.1.2 角色設定改成用講的（三步計畫的第一步）
- 分頁從七個縮成三個：聊天、角色、觀察者。
- 角色頁：上面是名字、年齡、職業、外表；下面是心理模組，每個模組一個文字框，附一句引導問題（例：「個人界線：什麼事他絕對不讓人碰？」）。不用再寫 JSON。
- 多一個「自由描述」模組，放在最前面，不知道該放哪一格的都可以寫這裡。
- 空著的模組不會存，也不會送給 AI；關掉的模組 AI 也讀不到。
- 可以新增自訂模組（自己取名字），也可以刪掉自訂模組。
- 整頁只要按一次「儲存角色」。有改了還沒存的內容，按鈕旁邊會提醒，換角色或關網頁前也會先問。
- 別名、性別、代名詞、背景、目前生活狀態、其他設定收進「更多基本資料」，平常折起來。
- 心理數值、關係數值、記憶容量、完整資料收進最下面的「進階」，平常折起來。
- 舊格式（JSON）的模組內容原封不動保留，畫面上會提示還有舊內容。
- 測試設定：加了 pytest.ini，跑測試時只跑 tests/，不會跑到垃圾桶裡的舊測試。
- 聊天和觀察者還是舊樣子（還會看到數字），第二步、第三步會改。
